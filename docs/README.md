# Food Rescue HQ: CodeTV Web Dev Challenge S3.E9

Team: Naya Moss + Nikema. Format: 30 min planning, 4 hr build, live demo.
Stack: Twilio plus Replit as the integration partner. Optional: ElevenLabs.

Concept: a food waste management app for events and conferences. An organizer reports leftover food on a quick form, Twilio calls nearby shelters and partner organizations, they press 1 to claim, and a live Replit dashboard tracks the rescue. Current source of truth: `00-current-plan.md`.
