# Food Rescue HQ

CodeTV Web Dev Challenge S3.E9 hackathon plan (Naya Moss + Nikema).

A food waste management app for events and conferences: a quick report form creates an incident, Twilio calls nearby shelters and partner organizations, they claim by keypad, and a live command center on Replit tracks the rescue.

- `plan.html`: visual plan, open in a browser
- `one-pager.html` / `one-pager.pdf`: the one-page summary to share
- `everything-we-need.html`: searchable checklist of everything required, with read-aloud
- `docs/`: full written plan (PRD, features, technical design, build plan, demo script, checklists)

Start with `docs/00-current-plan.md`, then `docs/README.md`. App code lives in the `Food-Rescue-HQ-02` repo.
